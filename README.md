# Backroundo

Kostenlose Mac-App, die dein Hintergrundbild automatisch wechselt – mit Fotos von Wikimedia Commons, gemeinfreien Gemälden aus dem Metropolitan Museum, Unsplash oder deinen eigenen Bildern.

**Webseite & Download:** https://badboy1308.github.io/backroundo/

- macOS 13 (Ventura) oder neuer, Apple-Chip & Intel
